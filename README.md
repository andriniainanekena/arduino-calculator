## Description

My first Arduino project applying what I've recently learned about Arduino programming and basic electronics.

## Features

- Addition, subtraction, multiplication, and division
- Numeric input using a 4x4 keypad
- Result display on an LCD screen

## Hardware Components

- Arduino Uno R3
- 4x4 Keypad
- 16x2 LCD Display
- Small Breadboard
- Resistor
- Potentiometer

## Tools

- Arduino IDE
